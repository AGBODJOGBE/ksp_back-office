# Décisions des fronts

Registre commun à `ksp_portail`, `ksp_shop`, `ksp_print` et `ksp_back-office` : ce tableau est identique dans les quatre dépôts, et un numéro a le même sens partout. Comme les ADR de `ksp_back` (`docs/adr`), une décision n'est jamais modifiée : une nouvelle décision la remplace en la citant. Une décision propre à un site commence par son nom (« Portail : », « Back-office : »).
